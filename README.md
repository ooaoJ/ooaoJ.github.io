# Portfólio — João Pedro Bento Sperandio

Portfólio pessoal em HTML, CSS e JavaScript, pronto para publicação no GitHub Pages.

## Estrutura

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── script.js
└── README.md
```

## Antes de publicar

Abra `index.html` e substitua:

- `SEU-USUARIO` pelo seu usuário do GitHub/LinkedIn.
- `SEU-EMAIL@EXEMPLO.COM` pelo seu e-mail.
- Os links `href="#"` dos projetos por demos reais, se existirem.
- Ajuste datas de formação quando quiser informar períodos exatos.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto.
3. Vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/root`.
6. Salve.

O site será publicado em um endereço semelhante a:

`https://seu-usuario.github.io/nome-do-repositorio/`

## Ícones

Os ícones são carregados pelo Bootstrap Icons via CDN.
